# SURAKSHA

Healthcare companion prototype for senior citizens living alone.

## Run in VS Code

1. Open this folder in VS Code.
2. Open Terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost link Vite gives you.

## Build
`npm run build`

## Vercel
Push to GitHub, import the repository in Vercel, choose Vite if detected, build command `npm run build`, output directory `dist`.

## Demo safety
Hospital listings use the supplied prototype dataset. Doctor details are fictional demo placeholders. Appointment availability, nurse verification, nurse-assisted visits and SOS are simulations. No real emergency service is contacted.
